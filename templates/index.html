What the pipeline does
  1. Collector — pulls the TESS light curve from MAST (astroquery), cached locally. Falls back to a synthetic curve offline.
  2. Memory — a vector store of prior literature for retrieval (RAG).
  3. Finder — detrend + box-least-squares transit search + IsolationForest outlier flag.
  4. Critic — LLM drafts a hypothesis, self-questions it attack-by-attack, vetoes or advances.
  5. Writer — drafts an IMRaD report citing the exact data logs.

running the 5 agents. TESS download + LLM reasoning can take 30–90 s.
